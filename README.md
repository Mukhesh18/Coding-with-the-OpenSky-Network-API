The Flight Information System is a Python-based tool that leverages the OpenSky Network API to retrieve, process, and display real-time global air traffic data. Equipped with features like advanced filtering, route enrichment, and statistics generation, it provides an intuitive terminal interface. Overall, the project effectively demonstrates practical API integration, data processing, and efficient caching techniques for developers and aviation enthusiasts.
 
 This was built for my 11th Grade Computer Science Project Report

The system must require it to have Windows OS, Python and MySQL to run the program

The program connects to the OpenSky API to retrieve and process real-time flight data. It presents an interactive menu allowing users to search, filter, view route details, and analyze flight statistics. Finally, the selected information is neatly displayed in a formatted table until exit.
